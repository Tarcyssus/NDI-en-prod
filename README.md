## 🚀 Lancement du projet

### 1️⃣ Prérequis
Assurez-vous d’avoir installé :
- [Docker](https://docs.docker.com/get-docker/)

### 2️⃣ Cloner le dépôt
```bash
git clone https://github.com/Tarcyssus/NDI-en-prod.git
cd NDI-en-prod
```

### 3️⃣​ Lancer le projet
- Lancer Docker
- Démarrer le conteneur du projet :

`docker compose up -d --build`

- http://localhost:8000/

### 4️⃣ Accès à l'application
- URL : [`https://ndi-en-prod-backend.labs.iut-larochelle.fr/`](https://ndi-en-prod-backend.labs.iut-larochelle.fr/)
